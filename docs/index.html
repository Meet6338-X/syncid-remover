Mathematical Foundations

How DeSynth Breaks AI Watermarks

Traditional operations like resizing or JPEG compression fail because SynthID is designed to survive them. DeSynth targets the mathematical vulnerabilities of the watermarking hypothesis.

01

Gaussian Frequency Split

Decomposes image into $I_{\text{low}} = G_\sigma * I$ and $I_{\text{high}} = I - I_{\text{low}}$. Steganographic signals live in the high-frequency band ($|I_{\text{high}}| \le 4.0$). Applying adaptive soft-shrinkage $\text{sign}(x) \cdot \max(0, |x| - \theta)$ eliminates watermark energy while retaining prominent edges.

02

8×8 DCT Mid-Frequency Jitter

SynthID relies on synchronized block relationships across 8×8 pixel matrices. By computing block-wise Discrete Cosine Transforms and perturbing the mid-frequency AC band $(u + v \in [3, 9])$, the periodic parity verification fails without affecting visual appearance.

03

Bitstream C2PA Sanitizer

Scans and strips JPEG APP11/JUMBF boxes, PNG caPt / c2pa chunks, Adobe XMP packets, and model prompt metadata. Rebuilds a canonical bitstream that registers 0 bytes of AI provenance.

Developer Integration

CLI & Python API Usage

DeSynth can be operated via our CLI, integrated into Python data pipelines, or deployed as a containerized FastAPI microservice.

# Install requirements
git clone https://github.com/Meet6338-X/syncid-remover.git
cd syncid-remover/apps/api
pip install -r requirements.txt

# Purify single image via CLI
python cli.py purify input.png -o clean.png --preset balanced

# Run batch folder neutralization
python cli.py batch ./input_images/ -o ./clean_images/

# Start FastAPI high-performance microservice
uvicorn main:app --host 0.0.0.0 --port 8000
